The artwork and trademarks belong to their respective owners. These files identify the named
services; they do not establish affiliation, provider approval, integration availability or a
certification. The reviewed source pages did not publish a separate redistribution licence for
these files. This repository's own code licence does not license these third-party marks.

Use the original aspect ratio and colours. The PNG wordmarks are intended for compact display at
their native resolution; enlargement needs a higher-resolution official source.

Cedar's September refinement caps the small Prometeo wordmark at 57 CSS pixels and Yape at 36 CSS
pixels, preserving two source pixels per CSS pixel. Plin stays at 44 CSS pixels. The provider's
current header still serves the same compact raster source; Cedar keeps those verified bytes and
uses a smaller display size instead of inventing a replacement mark.

## The wallets' app icons (20 September 2026)

`yape-icon.webp` and `plin-icon.webp` are the two wallets' app icons at 126 px, cut lossless from
the marks the public site already serves (`Rocoto-Labs/site`, `peru/banks/yape.webp` and
`plin.webp`, whose `manifest.json` carries each source). They are drawn at 63 CSS pixels or less,
two source pixels per CSS pixel, with the icon's own rounded corner. The bodega sign-up's Yape
screen and the customer's payment page use them where the wallet itself is the subject.
