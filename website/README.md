# Historical Peru marketing templates

This is the actual Rocoto Peru website source at `438dcaef9d1ace9ac745dce2403743efd1e59fd5` (22 September 2026): English/Spanish pages, original scroll/handset/demos, artwork, route copy and referral-link logic. It is separate from the advanced shop runtime selected by the release.

The credit offers, dates, lender language and legal pages describe the September 2026 product proposal. The public source package presents current implementation/proof status in `../docs/status.md`. Signup/contact actions lead to local setup until a recipient commissions their own sender and offer. The browser shop itself starts with `make dev` at the repository root.

Preview the templates with `python tools/serve-website.py` from the repository root, then open `http://127.0.0.1:18244/`. This serves the original route aliases on loopback. Your public configuration helper supplies the owned sender to `peru/owner.js`; actual inbound signup is the separate signed prototype API.

The Polyman handset model is CC BY4.0, with attribution in `peru/handset/model/CREDITS.md` and the original footer. Three.js, fonts, provider/bank marks and WhatsApp demo vendor code keep their included notices. Original commissioned artwork retains its generation/provenance README. Private merchant directories, investor/client files, later Artisan site work, account configuration and deployment history are outside this closure.
