# Rocoto Peru website

This is the original English and Spanish Rocoto Peru product website, adapted for Atelier at `/peru/` and `/peru/es/`. It retains the original scroll choreography, Polyman 3D iPhone, illustrations and simulated product journeys. The Open demo link leads directly to the sample shop workspace; GitHub and project documentation are alongside it. The website illustrates a planned credit concept, subject to lender assessment and approval. No signup or payment service is connected by this page.

Serve this directory at the web root; the two pages and their assets are under `peru/`. The original campaign source was recovered from `rocoto-site-robotuni/peru.html` (SHA-256 `0aa8ad737baf87135064d2983a05a97870d2e18623389c4d19621fb4441de03d`) and `peru/es/index.html` (SHA-256 `76339bb92034a9a9803dfdc658a18b92d72573e4b73748b2ee7bf91ed7621954`). Paths, headings, demo actions and planned-credit disclosures were updated for this release.
